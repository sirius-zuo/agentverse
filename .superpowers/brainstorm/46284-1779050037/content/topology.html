What agent topologies does Aether need to support?

This shapes the core orchestration model. Pick all that apply.

A

Pipeline

Agents chained sequentially — output of one feeds into the next.
Intake → Researcher → Summarizer → Writer

B

Supervisor / Worker

A coordinator agent dispatches tasks to specialist workers, collects results, and synthesizes.
Supervisor → [Coder, Reviewer, Tester]

C

Router / Specialist pool

An incoming request is routed to the best-fit agent from a registered pool based on capability or intent.
Router → [HR Agent | Legal Agent | Finance Agent]

D

Arbitrary DAG / Graph

Agents connected as a directed graph — any agent can pass to any downstream agent, with branching and merging.
A → B, A → C, B → D, C → D
